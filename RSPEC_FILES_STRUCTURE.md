## Test Execution Commands

### All Tests
```bash
bundle exec rspec
```

### By Category
```bash
bundle exec rspec spec/models/           # Model tests only
bundle exec rspec spec/controllers/      # Controller tests only
bundle exec rspec spec/requests/         # Request tests only
```

### By File
```bash
bundle exec rspec spec/models/user_spec.rb
bundle exec rspec spec/controllers/users_controller_spec.rb
bundle exec rspec spec/controllers/sessions_controller_spec.rb
bundle exec rspec spec/controllers/admin_controller_spec.rb
bundle exec rspec spec/controllers/application_controller_spec.rb
bundle exec rspec spec/requests/authentication_spec.rb
```

### With Options
```bash
bundle exec rspec --format documentation              # Detailed output
bundle exec rspec --color                             # Color output
bundle exec rspec --format documentation --color      # Both
bundle exec rspec --fail-fast                         # Stop on first failure
bundle exec rspec -p                                  # Profile tests (slowest)
```

## Adding New Tests

### Steps to Add Test
1. Create file: `spec/[type]/your_spec.rb`
2. Use existing patterns
3. Run: `bundle exec rspec spec/[type]/your_spec.rb`
4. Ensure all pass before committing

### Test Template
```ruby
require 'rails_helper'

RSpec.describe YourClass, type: :model do
  describe 'method_name' do
    context 'when condition' do
      it 'does something' do
        expect(result).to eq(expected)
      end
    end
  end
end
```

## Troubleshooting

### Tests Won't Run
1. `bundle install`
2. `bundle exec rails db:test:prepare`
3. `bundle exec rspec --version`

### Factory Not Found
1. Verify `spec/factories/users.rb` exists
2. Check factory syntax
3. Run `bundle exec rspec` (not direct rspec command)

### Database Connection Error
1. Ensure PostgreSQL is running
2. Check `config/database.yml`
3. Run database setup commands
